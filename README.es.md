# The Grand Continuity — mundo de demostración de Everend Forge

<a href="README.md">English</a>

Universo sintético conectado para probar WorldNotion, PathBranching y Compendium. Incluye canon, taxonomía, una historia ramificada con múltiples finales y una configuración de publicación.

## Cómo abrirlo

1. Descarga o clona este repositorio.
2. Abre la carpeta raíz como universo en WorldNotion.
3. Abre PathBranching para explorar la historia “The Last Acceptable Reboot”.
4. Usa Compendium para generar una publicación estática desde el universo.

~~~sh
cd ../everend-forge-compendium
npm run site:build -- ../everend-forge-demworld --out=dist-demo
~~~

Todo el contenido narrativo y de mundo es sintético; no deriva de canon privado ni de franquicias existentes.
